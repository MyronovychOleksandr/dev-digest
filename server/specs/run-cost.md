# Run Cost

Вартість прогону агента-рев'юера: фіксується в момент прогону й показується в UI.
UI-частина: `../../client/specs/run-cost.md`.

## Правила даних

- `agent_runs.cost_usd` записується один раз, при завершенні прогону. Ніколи не перераховується.
- Джерело: `usage.cost` від OpenRouter; інакше оцінка токени × прайс на момент прогону; інакше `NULL`.
- Якщо `usage.cost` є не в усіх спробах одного виклику, часткова сума не віддається: рахується оцінка від сумарних токенів.
- Оцінка можлива, лише коли токени є в усіх спробах. Відсутній, порожній чи нульовий `usage` → `NULL` (і в OpenRouter, і в OpenAI).
- `NULL` для: running, failed, cancelled, відсутній `usage`, невідома модель без `usage.cost`, прогони до фічі, рев'ю без `run_id` (seed).
- Нуль додаткових викликів моделі.

## API

| Роут | Поле |
|---|---|
| `GET /repos/:id/pulls` | `cost_usd` прогону, що створив останнє рев'ю PR (те саме, з якого береться `score`) |
| `GET /pulls/:id/runs` | `cost_usd` кожного прогону |
| `GET /runs/:id/trace` | `stats.cost_usd`; у trace, збережених до фічі, поля немає |

## Відповідність логу та OpenRouter

У лог прогону пишеться рядок `Cost: $0.00123456 · tokens 8200→1300` (або `Cost: n/a · …`).
Для OpenRouter-прогонів це сума генерацій цього прогону в Activity (retry і map-reduce дають кілька генерацій).

Відомі обмеження:

- оцінки (OpenAI/Anthropic напряму, fallback) з Activity не звіряються й у UI не позначаються;
- з BYOK `usage.cost` — лише комісія OpenRouter;
- витрати failed/cancelled прогонів не фіксуються.

## Поза обсягом

Backfill старих прогонів, агрегати й суми по PR, позначка «оцінка».

## Definition of Done

Кожен новий `done`-прогін із даними показує ціну в усіх місцях UI; без даних — `—`; цифра збігається з логом прогону і (OpenRouter) з Activity; тести й typecheck зелені.
