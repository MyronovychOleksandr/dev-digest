# Run Cost (UI)

Правила даних і API: `../../server/specs/run-cost.md`.

## Де показуємо

| # | Місце | Вигляд |
|---|---|---|
| 1 | Список PR, колонка **COST** (між STATUS і UPDATED) | `$0.012` — вартість останнього рев'ю PR |
| 2 | PR → Agent runs → заголовок акордеона в **Review runs**, перед часом | `$0.012` |
| 3 | PR → Agent runs → плашка вердикту всередині акордеона | `$0.014 · 8.2K→1.3K` |
| 4 | Drawer **Agent run** → Stats, плитка **COST** між Tokens і Findings | `$0.012` |

Timeline вартість не показує.

## Формат

| Значення | Показ |
|---|---|
| `null` / `undefined` | `—` |
| < 1 | 3 значущі цифри, кінцеві нулі обрізаються до мінімум 3 знаків: `$0.0123`, `$0.012`, `$0.0013`, `$0.060` |
| ≥ 1 | `$1.23`, `$12.35` |
| справжній `0` (безкоштовна модель) | `$0.000` |

Токени: `8200 → 8.2K`, менше 1000 — як є. Якщо токенів немає, показується лише ціна (або `—`).
